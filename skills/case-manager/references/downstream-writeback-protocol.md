# case-manager · 跨技能台账回写协议（共享）

> 本文件为套件内**所有下游文书 / 分析 / 报告类技能**的**唯一权威回写模板**。
> 下游技能通过尾部「案件管家联动（强制）」小节的一行 `> 引用本文件` 触达本协议，避免协议文本在 15+ skill 中逐字漂移。

---

## 触发时机

下游技能完成产出（md / docx / HTML / PDF / Zip）**之前**，必须先执行本协议。
若跳过本协议直接输出，视为违反套件铁律。

## 回写六步

1. **锁定 recordId**：以案件简称 / 案号 / 项目关键词在**台账**中 `keyword` 搜索
   → `COLLAB.sheet_search(sheet=ledger, keyword=<案件简称>)`
2. **读取当前"案件进展"字段值**（不覆盖历史，仅追加）
3. **拼接新条目**：
   ```
   原值 + "\n" + "{YYYY.M.DD}<本 skill 名>完成：<一句话成果摘要>"
   ```
4. **更新回写字段**：
   - "案件进展" ← 拼接后的字符串
   - "下一步动作" ← 参照《案件管家》§7 跨技能衔接矩阵中本 skill 对应行的下游默认动作
   - 有其他字段变化（阶段进度 / 开庭日期 / 结案状态）一并更新
5. **写入**：`COLLAB.sheet_update_record(sheet=ledger, recordId=<id>, fields={...})`
6. **然后再输出**下游文书 / 报告 / 回链

## 降级

- **台账搜索无结果**（新案未建档）→ 跳过回写，在输出末尾附加：
  > "本案尚未建档，请先通过 `/case-manager` 收案。"
- **`COLLAB.sheet_*` 后端不可用** → 跳过回写，附加：
  > "⚠️ 台账未自动更新（后端未连接），请手动记录本次产出。"

## 不阻塞

回写失败**不阻塞**文书输出——先保证下游产出交付，再在文末显式标注：

> ⚠️ 台账未自动更新，请手动记录。

## 本协议由谁维护

由 `/case-manager` 单点维护，路径 `skills/case-manager/references/downstream-writeback-protocol.md`。
下游技能仅需在尾部保留一行引用，禁止复制粘贴协议本体。
